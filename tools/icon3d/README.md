# 앱 아이콘(3D 일러스트) 만들기

홈 바로가기 아이콘(`img/icons/*.png`)을 만드는 도구입니다.
스타일 기준: **원래 이모지 크기(약 28px), 부드러운 파스텔 톤, 입체감은 살짝만** — 반짝임·진한 그림자 없이 위쪽 카드 일러스트와 어울리게.

- `render.html`: 브라우저(WebGL)에서 3D 모양을 직접 그려 투명 PNG로 뽑습니다. 아이콘마다 `SCENE` 번호.
  1 일정등록(달력) · 2 단체등록(세 사람) · 3 타임라인(스톱워치) · 4 마켓(쇼핑백) · 5 커뮤니티(말풍선) · 6 추천맛집(국밥) · 7 럭키드로우(선물상자)
- 새 아이콘은 `scene()`에 `SCENE==8` 같은 블록을 추가하고, 같은 조명·재질(`matCol`)을 그대로 씁니다.
- 뽑은 그림은 여백을 잘라 128×128로 줄여 `img/icons/`에 넣습니다.
